# ECONIGHT INVEST — 참가자 전용 시연 앱

2026 경제인의 밤 모의투자대회 참가자 시점 데모입니다. GitHub Pages에서 실행할 수 있는 정적 웹사이트이며, Supabase/관리자 권한/실제 참가자 간 동기화는 아직 **없습니다**.

## 사용 방법

1. 시작 화면에서 이름 입력 후 '시작하기'.
2. 대기실 ①에서 규칙 읽기 → 대기실 ②에서 8개 기업과 초기 주가 확인 → 대기실.
3. '시연 · 1라운드 시작'을 눌러 뉴스와 투자 화면 보기.
4. 종목의 '거래' → 매수/매도 → **+ / −**로 수량 선택 → 주문 실행. 가상 자금 1,000,000원.
5. '시연 · 주문 마감 후 결과 발표'를 누르면 해당 라운드 결과가 브라우저에서 무작위로 생성됩니다. 이 동작은 **시연 편의 기능이며 실제 대회에서는 관리자 주문 마감 후 서버에서 추첨**해야 합니다.
6. 다음 라운드로 이동해 4라운드까지 반복. 최종 순위에서 본인 성적, TOP 3 단상과 전체 50명 시연 순위 확인.

## 주가 변동 범위

각 기업의 등락률은 매 라운드 **−30.0%~+30.0%** 이내이며, 0%도 가능합니다. 같은 산업의 두 기업은 뉴스 결과에 따른 변동 방향이 같습니다. 두 기업의 추첨 비율은 각각 다르게 추첨됩니다. 실제 표시 수익률은 가격을 원 단위로 반올림한 결과를 기준으로 산출합니다.

## GitHub Pages 올리는 법

**방법 A: 기존 리포지토리에 적용**

1. `econight-participant-demo` 폴더 안 파일과 `assets` 폴더를 리포지토리 **최상단(root)** 에 업로드하세요. `index.html`이 리포지토리 첫 화면에 보여야 합니다.
2. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → Branch `main`, Folder `/(root)` → Save.
3. 배포 후 접속 주소: `https://<사용자명>.github.io/<리포지토리명>/` (정확한 이름은 GitHub Settings > Pages에서 확인).
4. Safari에서 새로고침하세요. 사이트 변경 후 예전 코드가 남아 보이면 브라우저 캐시를 새로고침하세요.

**방법 B: 새 리포지토리 사용**

1. GitHub에서 새 public repository를 만드세요. 예: `econight-invest-demo`.
2. 위 파일을 **폴더 자체가 아니라 폴더 안의 파일**로 올리세요.
3. Settings → Pages에서 `main` / `/(root)` 선택 후 배포하세요.

## 보안 및 데모 한계

- 이 시연판은 브라우저 localStorage에 이름과 거래 내역을 저장합니다. 브라우저마다 별도 시연이며 여러 참가자가 서로의 거래를 보지 못합니다.
- 마지막 TOP 3/50명 순위는 나를 제외하고 가상 인물/수익률로 채운 **시연 전용 순위**입니다.
- 시연판의 결과 추첨은 브라우저에서 실행되어 관리자 보안/감사/서버 무작위성 요건을 충족하지 않습니다. 실전 공개 전 Supabase 백엔드 작업이 필수입니다.
- GitHub Pages에는 관리자 비밀키, Supabase service_role 키 등 서버 비밀을 절대 업로드하지 마세요.

## V2 변경사항
- **3라운드:** 4개 산업 중 **2~3개 산업을 무작위 추첨**해 100조 원을 분산 집중 투자합니다. 선정된 산업은 상승, 나머지는 기존 보유 비중 축소라는 가상 시나리오에 따라 하락합니다. 주문 마감 전에는 선정 산업을 공개하지 않습니다.
- **결과 발표:** 뉴스 결말과 8개 종목 등락률을 보여준 후, 4개 산업 각각의 상승/하락 이유를 간단히 제시합니다. 거래 전 뉴스 화면에는 이유나 방향을 표시하지 않습니다.
- **등락률:** 각 라운드에서 −30%~+30%, 0% 허용. 같은 산업의 두 기업은 같은 방향이며 변동률은 서로 다릅니다(0% 보합이면 둘 다 보합).
